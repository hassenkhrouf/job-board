# AI Agent Instructions - Job Board Project

## Project Overview
This project is a lightweight job board platform focused on publishing job offers, public competitions, and career opportunities.

The main goal is:
- Generate organic traffic through SEO.
- Monetize using advertisements.
- Keep the platform simple, fast, and scalable.

## Development Rules

- Always understand the existing architecture before modifying code.
- Do not create unnecessary complexity.
- Prefer simple solutions over enterprise solutions.
- SEO and performance are top priorities.
- Write clean, maintainable code.
- Follow modern best practices.

## Coding Rules

- Use TypeScript.
- Use meaningful names.
- Avoid duplicated code.
- Keep components small.
- Add comments only when logic is not obvious.

## AI Workflow

Before implementing any feature:
1. Explain the approach briefly.
2. Identify affected files.
3. Implement the change.
4. Verify that nothing is broken.

Do not rewrite existing features without a clear reason.

## Product Mindset

Always consider:
- SEO impact.
- Page speed.
- User experience.
- Monetization opportunities.
