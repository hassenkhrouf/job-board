# AI_CONTEXT.md

# AI Context

## Project Name

Job Board Platform

---

# Project Goal

Build a modern, SEO-first job board website focused on:

- Job Offers
- Public Competitions
- Internships
- Remote Jobs

The website is designed primarily to generate organic traffic from search engines and monetize through advertisements.

---

# Business Goals

Primary Revenue:

- Google AdSense

Future Revenue:

- Sponsored Jobs
- Featured Companies
- Premium Visibility

---

# Development Philosophy

The project is NOT an enterprise HR platform.

It is intentionally simple.

Avoid unnecessary features.

Do not implement features unless they are part of the roadmap.

---

# Current MVP Scope

Included:

- Homepage
- Jobs Listing
- Job Details
- Categories
- Locations
- Search
- Simple Admin Dashboard
- SEO
- Advertisement Placement

Not Included:

- User Accounts
- Job Applications
- Messaging
- Payments
- Notifications
- AI Features

---

# SEO First

Every decision should consider SEO.

Priority:

1. Page Speed
2. Crawlability
3. Indexability
4. Internal Linking
5. Structured Data
6. Mobile Experience

---

# Performance Goals

Fast loading.

Minimal JavaScript.

Server Side Rendering whenever appropriate.

Optimized Images.

Clean HTML.

---

# UI Philosophy

Simple.

Minimal.

Professional.

Readable.

Content first.

---

# Architecture Goals

Keep the architecture clean.

Avoid overengineering.

Every folder should have a clear responsibility.

Components must be reusable.

Business logic should be separated from UI.

---

# AI Instructions

Before implementing anything:

1. Read every markdown document.

2. Understand the architecture.

3. Respect the roadmap.

4. Never change project architecture without explanation.

5. Never introduce unnecessary dependencies.

6. Keep code readable.

7. Optimize for SEO and performance.

---

# Final Rule

This project aims to become a real production website.

Think like a senior software engineer building a commercial product.
