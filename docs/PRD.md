# Product Requirements Document (PRD)

## Product Name

Job Board Platform


# Product Overview

A lightweight SEO-first platform that aggregates and publishes job opportunities.

The website focuses on simplicity:
- No user registration.
- No complex accounts.
- Fast access to job information.


# Target Users

## Job Seekers

People searching for:

- Private jobs
- Public competitions
- Internships
- Remote jobs


## Companies

Companies that want visibility for their recruitment announcements.


# Core Features

## Job Listings

Users can:

- Browse jobs
- Search jobs
- Filter by category
- Filter by location
- Open job details


## Job Details Page

Each job contains:

- Title
- Company
- Location
- Category
- Description
- Requirements
- Application link
- Publication date
- Deadline


## Categories

Examples:

- IT
- Finance
- Engineering
- Marketing
- Administration
- Education


## Locations

Examples:

- Tunis
- Sfax
- Gabes
- Sousse
- Remote


# Business Goals

Primary objective:

Generate organic traffic and monetize through advertising.


Revenue sources:

1. Google AdSense
2. Sponsored job announcements
3. Featured listings


# Non Functional Requirements

## Performance

- Fast page loading
- Optimized images
- Server-side rendering


## SEO

Every job must have:

- Unique URL
- Metadata
- Structured data
- Sitemap entry


## Mobile First

Most visitors are expected from mobile devices.
