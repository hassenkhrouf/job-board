# SEO Strategy


# Main Goal

Generate organic traffic from Google search.


# URL Structure


Jobs:

/jobs/job-title


Categories:

/jobs/category/software-development


Locations:

/jobs/location/tunis



# Metadata


Every page must contain:

- Title
- Description
- Open Graph tags
- Twitter cards


# Structured Data


Use Schema.org:

JobPosting


Required fields:

- title
- description
- datePosted
- hiringOrganization
- jobLocation
- validThrough



# Technical SEO


Required:

- sitemap.xml
- robots.txt
- canonical URLs
- breadcrumbs


# Content Strategy


Create pages targeting searches:


Examples:

"emploi développeur tunisie"

"concours fonction publique tunisie"

"stage informatique tunisie"

"remote jobs arabic"
